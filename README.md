
# Weather App

A simple weather app that shows the current weather of a city.
It helps users check temperature and weather conditions using a weather API.

## Features

- Search weather by city name
- Display current temperature
- Show weather conditions
- Display humidity and wind speed
- Simple and user-friendly interface
- Fetch live weather data from an API
- Show weather icons

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- Weather API

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `weatherApp.html` in your browser.
4. Search for a city to check its weather.
